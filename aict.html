Motivation & Problem Statement

The Challenge

Traditional cloud-based assistive systems face critical limitations:

  • Privacy Concerns: Sensitive personal data transmitted to external servers
  • Network Dependency: Requires constant internet connectivity
  • Latency Issues: Network delays impact real-time interaction
  • Data Security: Risk of unauthorized access to user information

Our Solution: Privacy-First Edge AI

  • ✓ 100% Offline Operation - Complete data sovereignty
  • ✓ Multimodal Integration - Vision, speech, and text processing
  • ✓ Real-Time Performance - Sub-1.2s latency per modality
  • ✓ Resource-Efficient - Runs on Raspberry Pi 5

Experimental Methodology

Testing Framework

Environmental Conditions

  • Lighting Scenarios:
    • Well-lit: 400-500 lux (office)
    • Moderate: 100-200 lux (indoor)
    • Dim: 30-50 lux (low-light)
  • Audio Conditions:
    • Quiet: <40dB ambient
    • Noisy: 60-70dB ambient

Performance Metrics

  • Processing Latency: End-to-end measurement from input to audio feedback
  • Accuracy Metrics:
    • Precision = TP / (TP + FP)
    • Recall = TP / (TP + FN)
  • Resource Utilization: CPU, memory monitoring at 100ms intervals
Testing Protocol: All measurements repeated 50 times per condition. Results reported as mean ± standard deviation. Statistical validation using paired t-tests (p < 0.05).

Application Scenarios

  • Scenario 1 - Environmental Awareness: Object detection for obstacle identification (Target: <1000ms)
  • Scenario 2 - Text Reading: OCR for documents and signage (Target: <1500ms)
  • Scenario 3 - Social Interaction: Face recognition for identifying individuals (Target: <1000ms)

Resource Utilization Analysis

Efficient Resource Management

CPU Utilization

  • Vision Module: 45.2% (efficient object detection)
  • Speech Module: 28.6% (lowest resource demand)
  • OCR Module: 35.8% (balanced processing)
  • Face Recognition: 38.1% (optimized inference)
  • Combined Operation: 80-90% (peak utilization)

Memory Management

  • Baseline Usage: 1.2 ± 0.2 GB
  • Peak Load: Stable at 1.4 GB
  • Adaptive Buffers: 10-50 command capacity
  • Stability: Zero overflow events in 50-hour test

Dynamic Quantization Strategy

Intelligent Performance-Accuracy Trade-offs:

  • Low Load (<50% CPU): FP16 precision → 85.3% accuracy
  • High Load (>80% CPU): Automatic INT8 quantization → 81.2% accuracy
  • Result: 4% accuracy trade-off maintains 850ms latency and prevents system unresponsiveness
Key Achievement: Effective multimodal AI execution on resource-constrained hardware through priority-based scheduling and adaptive resource allocation

Privacy-Performance Trade-off Analysis

Privacy Score Methodology

Composite Privacy Metric:

Privacy Score = 0.4 × Lp + 0.4 × Nt + 0.2 × Uc

  • Lp: Local processing (10 if fully local, 0 if cloud-dependent)
  • Nt: No external transmission (10 if zero transmission, 0 otherwise)
  • Uc: User control over data (scale 0-10)

Target Application Context

✓ Suitable For

  • Stationary or slow-moving users
  • Environmental scanning and awareness
  • Document and label reading
  • Social interaction assistance
  • Indoor navigation at walking pace

⚠ Current Limitations

  • High-speed navigation (<500ms required)
  • Rapid obstacle avoidance during running
  • Extreme low-light conditions (<30 lux)
  • Very high ambient noise (>70dB)
Navigation Note: High-speed navigation typically requires sub-500ms latencies. Our system achieves application-appropriate latencies for stationary/slow-moving scenarios. Hardware acceleration (Coral TPU, RPi AI Kit) expected to enable 200-400ms latencies for navigation.

Conclusions & Future Directions

Key Achievements

  • Privacy-First Design: Complete offline operation with 9.8/10 privacy score
  • Multimodal Integration: First demonstration of 4+ AI modalities on Raspberry Pi 5
  • Novel Optimizations: 23-31% latency reduction through intelligent resource management
  • Practical Viability: Sub-$200 hardware cost enables widespread deployment
  • Robust Performance: Zero crashes in 50-hour continuous testing

Current Limitations

  • Navigation Constraint: Targets stationary/slow-moving scenarios
  • Environmental Sensitivity: Performance degradation in extreme conditions
  • Language Support: Currently limited to English

Future Research Directions

  • Hardware Acceleration: Integration of Coral TPU or Raspberry Pi AI Kit
    • Target: 3-5× speedup → 200-400ms latencies
    • Enable high-speed navigation applications
  • Enhanced Preprocessing: Robust algorithms for challenging conditions
  • Multi-language Support: Expand accessibility to non-English users
  • Field Evaluation: Real-world testing with target user populations
